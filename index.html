Campus Maintenance and Complaint Tracking System

An intuitive web-based application developed to manage campus maintenance complaints efficiently. Students can seamlessly register issues, while maintenance staff track, assign, and resolve them from Pending to In Progress and Resolved.

Maintenance Complaint Categories

Selectable issue areas covering all physical and digital campus infrastructure

Electrical Problems

Fans, lights, wiring, power sockets, switchboards, ACs, and electrical supply issues.

Plumbing

Washroom taps, pipeline leakages, drainage blockage, water coolers, and tank maintenance.

Cleaning & Hygiene

Classroom floor cleaning, trash disposal, corridor hygiene, and restroom sanitation.

Furniture

Damaged desks, broken chairs, podiums, whiteboards, doors, and window latch repairs.

Internet Connectivity

Campus Wi-Fi drops, LAN ports, Ethernet switches, intranet portal accessibility.

Classrooms

Projectors, audio systems, smartboards, ventilation, and lecture hall amenities.

Laboratories

Lab equipment power, chemical fume hoods, test bench gas supply, computer lab PCs.

System Technical Specifications

Hardware and software configurations documented for deployment

Hardware Configuration

Minimum baseline requirements
  • Processor Intel Core i3 or above
  • RAM 4 GB or above
  • Hard Disk 20 GB free space
  • Monitor 1366 x 768 resolution or above
  • Peripherals Standard Keyboard & Mouse

Software Configuration

Technology stack & tools
  • Operating System Windows 10 / 11
  • Backend & DB Supabase (PostgreSQL) / C# ASP.NET
  • Frontend HTML5, CSS3, JavaScript
  • Database Engine Supabase Cloud PostgreSQL
  • Realtime Sync Supabase Realtime WebSockets
  • Supported Browsers Google Chrome / Microsoft Edge
